# Azure Research

## What is Azure?

Microsoft Azure is a cloud computing platform provided by Microsoft. It offers services for computing, storage, databases, networking, and security.

## Main Services

- Azure Virtual Machines – virtual computers
- Azure Blob Storage – cloud storage
- Azure SQL Database – managed database
- Azure Virtual Network – cloud networking
- Azure Functions – runs code without managing servers

## Advantages

- Scalable
- Reliable
- Secure
- Many cloud services
- Flexible pricing

## Common Uses

Azure can be used for:

- Websites
- Mobile applications
- Databases
- File storage
- Backup systems
- Business and university systems
