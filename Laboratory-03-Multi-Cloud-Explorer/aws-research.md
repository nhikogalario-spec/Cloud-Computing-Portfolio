# AWS Research

## What is AWS?

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It provides services for computing, storage, databases, networking, and security.

## Main Services

- Amazon EC2 – virtual servers
- Amazon S3 – cloud storage
- Amazon RDS – managed databases
- Amazon VPC – cloud networking
- AWS Lambda – runs code without managing servers

## Advantages

- Scalable
- Reliable
- Secure
- Many cloud services
- Pay-as-you-go pricing

## Common Uses

AWS can be used for:

- Websites
- Mobile applications
- Databases
- File storage
- Backup systems
- University systems
