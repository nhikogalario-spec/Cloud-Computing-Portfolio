# Google Cloud Platform (GCP) Research

## What is GCP?

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It provides services for computing, storage, databases, networking, and security.

## Main Services

- Compute Engine – virtual machines
- Cloud Storage – cloud storage
- Cloud SQL – managed databases
- Virtual Private Cloud (VPC) – cloud networking
- Cloud Functions – runs code without managing servers

## Advantages

- Scalable
- Reliable
- Secure
- Fast global network
- Many cloud services available

## Common Uses

GCP can be used for:

- Websites
- Mobile applications
- Databases
- File storage
- Data analysis
- University and business systems
