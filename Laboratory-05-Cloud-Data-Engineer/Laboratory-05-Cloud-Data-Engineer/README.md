# Laboratory Activity 5: Mission 5 - The Cloud Data Engineer

## Mission Overview
Assigned to CloudNova Technologies as a Cloud Data Engineer, this mission focused on deploying a scalable, S3-compatible Object Storage server using MinIO running inside Docker. The objective was to configure a resilient storage backend for client photo uploads.

## Objectives
* Differentiate between Block, File, and Object Storage architectures.
* Deploy an S3-compatible MinIO server using Docker environment variables.
* Access and navigate the MinIO Web Console using port forwarding (`9001`).
* Create a storage bucket (`client-photos`) and upload sample object files.
* Document technical workflows and architecture decisions in Markdown.

## Tools Used
* **Containerization:** Docker
* **Object Storage Engine:** MinIO (S3 Compatible)
* **Environment:** KillerCoda Ubuntu Playground / Local Docker Engine
* **Documentation & Version Control:** GitHub, Markdown

## Skills Learned
* S3 API paradigms and object storage architecture.
* Secure container deployment using Docker environment flags (`-e`).
* Managing bucket policies, object uploads, and web console port mapping.
